# 供电与回馈：第四阶段未放行检查点

本页记录可核实的候选和拒绝理由，不是可直接通电的接线说明。第四阶段工程验收仍未通过；它还包括实际线束、保护定值、安装与热核算，不能只靠 CAN 带宽计算完成。

## 已核实的制动候选

ODrive Regen Clamp 是现售独立回馈管理模块，串接上游电源与下游电机驱动器，外接独立制动电阻。公开范围10–58V；自由空气20A、加散热板40A、主动散热80A的正向电流条件不同。制动触发为输出超过输入约2.35V，最大2.50V；板、接线端子版本、带散热板质量分别28/47/79g，板包络66×50×15.3mm。来源：[厂家数据表](https://docs.odriverobotics.com/v/latest/hardware/regen-clamp-datasheet.html)。

这**不能直接放行当前6S方案**：电池满充25.2V时，最大触发点可到27.7V，尚未算瞬态过冲；AK48-2405-2D-A2 的连续电压上限和允许回馈限值仍缺可靠厂商确认。保护模块自己的额定58V不能替代下游驱动器额定。原有44×48×38mm、93g的保护占位也不能代表该模块加制动电阻、支架与线缆的实际安装。

厂家要求限制电池接入浪涌，并说明制动电阻的瞬时电流和平均散热必须分别选型；温度保护触发时模块会禁用。来源同上。当前没有本机最大负机械功率、持续占空和壳内散热结论，不能把350W正机械功率限制直接用作回馈功率上限。

## 当前同版回馈核算

[受控机械回馈包络](../evidence/current_regeneration_envelope.json)使用当前10.3578562kg装配的17个主母线轴：连续设计力矩乘速度的保守总包络为468.769W，峰值模型包络890.429W。独立5V头部轴另有0.42W连续机械包络，不能假定普通降压模块把它的回馈送回主母线。此处是条件机械要求，不是实测电气回馈；只有相关限值持续生效时才成立，也未覆盖失控停机和磁场储能。350W正向限值不限制负功率，新硬件调度只补上当前契约已有的正向检查。

按旧方案的20V低电压假设与满电加触发上限27.7V作条件计算，电阻需同时满足`R≥Vmax/I`和`R≤Vmin²/P`。这里保守要求每次导通电流也不超过所比较条件；不是PWM热模型。对连续轴包络，20A自由空气条件的理想区间为空，40A散热板条件约0.693–0.853Ω；峰值包络在40A条件也为空，80A／最长3秒条件约0.346–0.449Ω。这些条件来自[厂家数据表](https://docs.odriverobotics.com/v/latest/hardware/regen-clamp-datasheet.html)；实际阻值容差、脉冲能量、占空、温升和驱动器电压窗口仍待闭合。没有据此指定采购电阻或宣称原有93g占位可容纳整个保护链。

80mm整机落差的重力能约8.129J，示例2200µF电容从24V到25.2V仅储存约0.06494J。另核对已保存的19.9秒自由根夹取—放回动作：199个几何快照的重力势能范围约9.857J、累计下降约11.431J。快照没有充分采样的速度和控制力矩，不能拿这些数当完整停止能量或电阻实测热负荷。因此旧12J设计预留仍不是放行依据；没有重新扩训PPO或修改动作来迎合电阻选型。

计算入口：`scripts/diagnostics/check_goose_current_regeneration.py`。当前模型和记录轨迹哈希均保留；没有把上述条件计算写成实物通过。
