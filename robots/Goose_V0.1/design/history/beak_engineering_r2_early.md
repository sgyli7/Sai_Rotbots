# Goose_V0.1 — 嘴部机械方案 R2
## 一体式鹅喙平行夹持机构

日期：2026-09-27  
状态：方案设计与理想平面运动学算例；不是制造 CAD 或实机验收。  
范围：替换步行鹅的嘴部机构及对应物料；已选定的身体、双足和颈部总体方向保持不变。

## 1. 设计结论

采用“固定上喙 + 平行运动下喙 + 单舵机 + 嘴内柔顺接触垫”。
上下喙本身就是两片夹指，不在下巴外挂另一把夹爪。

外部轮廓和内部接触面分开设计：外部收尖、喙根较高、上背拱起，闭合时形成鹅嘴；内部设置相对的夹持面。灵活性由下喙运动轨迹、接触形状及现有头部滚转共同提供，不靠新增多台嘴部电机。

首轮目标是拾取指定轻物并可控释放。50 g 为第一阶段试验负载；100 g 为升级测试工况，不是适用于所有形状的额定载荷。鹅嘴台架通过不等于整机持物步行通过。

## 2. 造型规则

- 俯视从宽根渐收至窄、钝的前端，不做矩形前沿和全长等宽的鸭嘴板。
- 侧视上喙有高度和略拱的上背，下喙较浅，闭合后形成连续楔形；不使用猛禽式大钩尖。
- 上喙的高度来自空腔与加强筋，而非实心加厚。
- 深色部分只出现在口缝和口腔接触区；工作垫和机构不形成外伸的第三个夹爪。
- 相机仍装在固定头架上，不装在运动下喙上。上喙抬高后必须检查相机视锥，不能假定原视野不变。
- 两颊传动罩随真实零件包络设计；不得为了隐藏机构而随意放大整个鹅头。

以下是原型设计输入，不是由已有图片测得的尺寸：

| 参数 | 原型目标 |
| --- | --- |
| 外露喙长 | 约 60–65 mm |
| 橙色喙根宽 | 约 30–34 mm |
| 前端宽 | 约 12–14 mm，圆钝收尖 |
| 外露上/下喙闭合根部总高 | 约 26–30 mm；后方两颊机构空间单独检查 |
| 常用净开口 | 约 0–25 mm |
| 最大净开口目标 | 约 30 mm；理想运动行程约 32.1 mm |
| 可换接触垫厚 | 初试约 2 mm，按压缩量和保留结构调整 |
| 嘴部模块质量目标 | 不超过 65 g，包含嘴部电机、传动、支架、软垫与线材；不含相机、头壳和颈关节 |

嘴部重量必须独立称量，再与相机、头壳和头部关节合并形成颈部真实末端负载，不能把 65 g 当作整个头重。

## 3. 机构拓扑

### 3.1 固定部分

上喙固定在口部承力架上。承力架连接头部内框，并承接下喙的两个固定转轴。电机位于喙根后方，不放在嘴尖。

### 3.2 运动部分

采用竖向固定支点的平行四边形机构：

- 两个固定转轴在侧视中上下排列。
- 两根等长摆杆连接下喙后部的两个等间距转轴。
- 下喙与其后部立耳构成同一刚性连杆，因此理想运动时下喙姿态不变。
- 左右两侧各有两根摆杆，共四根；横向同轴支撑抑制偏心抓取造成的歪斜。
- 一台舵机经约 2:1 减速驱动一根固定转轴，四连杆约束其余运动。
- 两侧支撑的同轴度和轴向释放必须明确，避免打印公差使双侧机构卡滞。

这是让下喙本身运动的夹持机构，不是把成品平行夹爪塞进另一个鹅嘴外壳。

### 3.3 与普通张嘴铰链的差异

普通转动下喙的内表面会随开口倾斜，物体可能只受到边缘接触；斜接触还可能产生向外的分力。平行下喙的设计目的，是让有效接触面在不同开口下保持相对，减少对接触角度的依赖。软垫摩擦、物体形状和偏心力矩仍然需要验证。

代价是根部零件数量增加，而且下喙不是纯竖直移动。这些代价在本方案中显式保留，不称为“完美平行直线夹爪”。

### 3.4 已计算的理想平面运动学

局部坐标：X 向前，Z 向上，转轴沿 Y。以下数字只是可行的初始参数组。

- 两根等长摆杆：L = 25 mm。
- 固定支点竖向间距：h = 14 mm；运动支点间距相同。
- 摆杆角度 q 相对 +X 测量。
- 闭合位置 q = +40°；张开位置 q = −40°。
- 舵机/摆杆角位移比 i = 2。

令 A=(0,0)、D=(0,h)，则：
B=(L cos q, L sin q)
C=B+(0,h)

理想下喙参考平面的开口变化：
g(q) = L [sin(40°) − sin(q)]

相对闭合位置的水平位移：
dx(q) = L [cos(q) − cos(40°)]

算例结果：

| 项目 | 结果 |
| --- | --- |
| 下喙理想开口行程 | 32.139 mm |
| 行程内最大前向偏移 | 5.849 mm |
| 全开与闭合的水平位置差 | 0 mm |
| 理想下喙姿态变化 | 0° |
| 2:1 减速下的舵机角行程 | 160° |
| 距离支点/摆杆共线的最近角度裕量 | 50° |

全行程没有经过这组理想连杆的共线位形，但这不等于三维零件不干涉。尚未验证齿轮、轴承法兰、连接螺钉、相机、护罩和上下喙之间的碰撞。

特别注意：闭合过程存在水平扫动，不能宣称夹点完全固定。需要降低接触阶段速度；对被固定物体，必要时用头部运动补偿。夹取自由物体时，要观察其是否被下喙推走。

2:1 只是传动比设计输入。齿数、模数、轴向错层和轴承安装必须由完整装配决定；14 mm 支点间距也允许为真实齿轮包络调整。不能直接把这组参数当作一张已解决全部装配的加工图。

## 4. 接触面，而非额外手指

### 4.1 同一副嘴的三个接触区

| 区域 | 几何和材料意图 | 首轮测试对象 |
| --- | --- | --- |
| 嘴尖前约 10–15 mm | 窄、相对的柔性接触面，前沿钝化 | 拉环、线绳、布条边缘、有可接近边缘的薄片 |
| 中段 | 浅 V 形软槽，初版按长条物沿嘴长方向定位 | 笔杆、短棒、轻型工具柄 |
| 靠近嘴根的内侧 | 较宽软垫和浅容纳凹区，不做闭合锁钩 | 指定小积木、轻型壳体、局部较厚的把手 |

这是同一副可换衬垫上的分区，不是三套末端工具，也不需要自动换嘴机构。

### 4.2 被动微顺应

下喙内放一个可拆压垫托，以小转轴和弹性回正件允许约 ±4° 的俯仰微调；设置硬限位，不允许整个嘴尖软塌。上喙使用固定柔性垫。

该被动角度不是新增主动自由度，不增加电机。目标是让偏斜的小物体获得更好的接触，而不是实现完整包络、灵巧手或已验证的“自适应抓取”。

Yale OpenHand 证明了被动柔顺和定制接触面是一条可研究的抓取路线；其手型、尺度和载荷不构成本方案性能证据，也不直接复制其非商业 CAD。[R4]

### 4.3 侧头抓取

利用已有 head_roll 候选轴改变夹持方向。侧头约 60–90° 可以把上下夹变成侧向夹的姿态意图，但头颈真实可达范围、自碰撞及线缆扭转必须验证；本轮不假定已经有 90° 可用行程。

侧头不能让下喙穿过桌面。贴地硬币、没有可接近边缘的薄纸、扁平贴合件，均不作为第一版必达对象。优先夹物体的边、把手或拉环，而不是要求嘴跨越整个大瓶身。

## 5. 驱动选型与载荷算例

### 5.1 首选样件

使用一台 ROBOTIS DYNAMIXEL XL330-M288-T：

- 官方尺寸 20 × 34 × 26 mm，重量 18 g。
- 推荐 5 V，允许输入 3.7–6.0 V。
- 支持电流控制和基于电流的位置控制。
- 5 V 下的 0.52 N·m 是堵转扭矩，不能当持续工作能力。[R1]

本轮保留这台电机，不默认增加第二台嘴部电机或更换全部关节驱动。选择的重点是重量、可采购来源、可查询控制表，以及与既有候选总线的衔接。

官方美国商店本次可见列价 USD 27.49，但同页出现售罄标记和购物按钮，库存不能据此确定；中国交付和价格需要代理商确认，不作为现货下单承诺。[R2]

### 5.2 100 g 对置摩擦夹持算例

假设：

- 物体质量 m = 0.10 kg；
- 向上加速度 a = 3 m/s²；
- 接触摩擦系数 μ = 0.4（假设，不是所选硅胶实测值）；
- 安全系数 S = 2；
- 两侧均有接触，每侧法向力为 N；
- 不计物体偏心转矩，仅计算滑落。

所需单侧法向力：
N ≥ S m(g+a)/(2μ) ≈ 3.203 N

因此可先将指定物体测试的法向夹力放在每侧约 2–4 N 的研究范围，按实际滑移、压痕和材料情况调整。这个范围不是人体接触安全标准。

对理想平行机构，在切向接触力可忽略的简化下：
τ_motor ≈ N L cos(q)/(i η)

取 i=2、假设传动效率 η=0.65，得到约 0.047–0.062 N·m。尚未加入下喙重量、轴系摩擦的不确定性、齿隙、斜向反力和冲击。这个算例支持进入台架测试，不证明电机长期可靠。

若存在切向力，应用完整雅可比项，而不是继续使用仅竖直力公式。嘴长不直接出现在上述纯平移功率关系里，也不意味着嘴长不影响刚度、轴系反力和偏心转矩。

## 7. 控制与工程集成

上游 MicroDuck 将嘴从其14维步态策略中分开，在 model.rs 中以0..1开口映射到原嘴关节的−5°..30°。[R3] 本方案借鉴“嘴单独控制”，不复用原角度范围或原机构。

Goose 保留一个主动嘴部控制量，但需换成新机构的开口/电机角映射。平行四连杆作为真实约束或经验证的等效机构建模；下喙被动压垫单独记录顺应性。物体保持自由接触，不使用焊接、瞬移或隐藏抓附。

动作顺序：预开口 → 低速接近 → 限流闭合 → 小幅试抬/确认 → 收颈搬运 → 放稳后张嘴。模式转换和夹力提升必须有上限；不能一旦识别到“有物体”就自动追求最大夹力。

两项厂商细节直接影响实现：

1. XL330的电流测量位于输入侧，与瞬态电机相电流不同；电流不是直接的夹持力传感器。必须建立“开口位置×电流×实际接触力”的台架标定。[R1]
2. 基于电流的位置模式不使用常规Min/Max Position Limit作为运动范围限制。控制端需要自己的角度/行程检查，机构也需要止挡；切模式后检查相关参数重置。[R1]

故障工况：不假定断电一定张嘴，也不保证掉电保住物体。设计可手动释放的机构维护路径；初样只在固定台架、低高度、非易碎物体上测试。软垫和限流不是儿童/宠物接触认证。

## 8. 验证顺序与放行条件

| 阶段 | 检查内容 | 建议放行口径 |
| --- | --- | --- |
| 真实包络CAD | 导入电机和相机尺寸；布置轴、法兰、齿轮、线材；全行程检查 | 30 mm级净开口可实现；无干涉；相机工作区未被新上喙不可接受地遮挡 |
| 无负载机构样件 | 开合、下喙姿态、间隙、左右同步 | 1000次开合无卡滞/松脱；记录姿态误差和磨耗，不只看能否动 |
| 定量夹持 | 分开测试拉环、杆件、块状物、薄边；测夹力与拉脱力 | 50 g指定物先测；之后100 g指定物；记录每种形状的成功率和失败方式 |
| 暂定重复性 | 每类指定物20次拾取与释放 | 初始研究门槛18/20；不据此推导通用抓取成功率 |
| 负载与热 | 指定物保持60 s、重复工作循环10 min | 电流/温升处在事先设定范围；无持续堵转、软垫撕裂或意外释放 |
| 颈部/全身 | 加入实测头嘴质量、抓取偏心和侧头姿态 | 独立验证可达、自碰撞和稳定性；嘴部台架不能代替这一步 |

必须单列失败情形：贴地薄片、光滑重物、无法进入的窄缝、明显偏心的长物体、湿滑接触、侧头角度不可达。

只有真实零件装配关系通过后，下一张外观图才可依据CAD生成。造型评审检查的是“固定上喙、平行下喙、窄尖和真实接触区”是否表达正确，而不是再次随机生成一张更厚的嘴。
