# Goose 常规 DYNAMIXEL 候选执行器事实比较

核对日期：2026-09-28（中国大陆）。背景：首版同时需要轻量日用品拾取与小车拖拽，并保留紧凑、长颈、双足方向。本文仅核对指定的五组常规目录候选及其齿比变体；不改 BOM，不选择关节配置，不采购。已有 X330 取证见 [primary_sources_review.md](primary_sources_review.md)。

## 最影响替代选择的事实

- XL430-W250 与 XC430-W240/W150 没有电流控制、Current-based Position Control 或 Present Current；地址 126 是推断的 Present Load。它们不能直接替换依赖 X330 电流字段与限流位置模式的控制接口。
- XM430-W210/W350 有上述电流模式与反馈。与 23 g XC330 相比，单只 XM430 的官方质量为 82 g，增加 59 g；替换 10 只仅执行器质量就增加 590 g，尚不含支架、线缆与电源变化。增加力矩同时也增加机器人自重，需重新核算。
- 官方商店的 estimated rated torque 全部注明按堵转力矩的 20% 估算。它不是给定关节姿态、环境温度、散热、负载周期下的连续实测能力，不能据此宣布已通过拖拽或步行。

## 电流功能与接口差异

来源为上表各精确型号官方 eManual 的 Operating Modes 和 Control Table。

| 组别 | Current Control / Current-based Position（模式 5） | 电流或负载反馈 | 对替代评审的含义 |
|---|---|---|---|
| XC330-M288 / XL330-M288 | 两者均支持 | Present Current 地址 126；1 mA/单位；另有 Current Limit 和 Goal Current | 有电流反馈与限流位置模式，但不等于已经标定输出扭矩/夹持力 |
| XL430-W250 / XC430-W240/W150 | 均不支持 | Present Load 地址 126；0.1%/单位；官方明确为内部输出推断，非扭矩传感器测量 | 不能把相同地址解码为 X330 的 mA；不能将负载百分比替代真实电流限值或夹持力 |
| XM430-W210/W350 | 两者均支持 | Present Current 地址 126；2.69 mA/单位；另有 Current Limit 和 Goal Current | 功能方向更接近 X330，但电流量纲、动力学、机械包络与电源均需重新适配 |

模式 5 下的位置限位需要单独处理：官方模式说明与 Goal Position 说明表明 Min/Max Position Limit 只约束模式 3，不能默认模式 5 自带同样关节边界。Present Current 也不是输出力传感器；传动摩擦、效率与装配条件仍需标定。官方 eManual 另指出实际性能更接近逐步增载的性能曲线，通常低于堵转峰值；性能曲线本身也不等于 Goose 的热稳定连续负载试验。见 [XL430 堵转与性能曲线说明](https://emanual.robotis.com/docs/en/dxl/x/xl430-w250/#control-table)。

## 需要带回设计对齐的比较条件

以下为工程判断，尚非最终架构选择：

1. 如果拖拽、拾取和步行要保留电流反馈与限流位置控制，比较重点是 **X330 与 XM430 的分工**；XL430/XC430 应作为另一个控制能力较少的方案评估，不能静默平替。
2. XM430-W350 比 W210 在相同质量/推荐电压下有更高堵转与估算力矩、较低空载速度；选用哪种需要先核算目标关节的扭矩-速度轨迹，而非只按峰值选型。
3. 先由真实 CAD 质量、关节力臂、拾取目标与实测拖拽起动/滚动阻力建立负载预算，再判断哪些关节需要升级。小车载荷质量不能直接等同于机器人嘴部承受的拉力。
4. 本轮没有取得任一候选在 Goose 装配中的连续温升、带载速度、输出扭矩/电流标定与冲击寿命实测。工程方案可以先完成计算与模型验证，实际连续承载与步行仍须通过用户已定义的独立实物门槛。
