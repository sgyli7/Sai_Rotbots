# Goose 第一阶段：结构与物理参数交接

**交付版本：`goose_stage_one_si_v1`，18 轴，适用于初始 PPO / 控制策略实验。**

本轮交付的主线是可读取、可追溯的结构与物理参数。模型能加载、运动链/惯量一致性检查已通过，也已用独立的自由根物理检查确认没有隐藏支撑。**尚不能宣布整机硬件硬冻结或 Sim2Real 验收通过。** 嘴部持续夹持输出、电源配套和低位拾取控制仍有明确未决项。原外观资料、历史采购表及 RC2 模型均保留；旧 16 轴策略不能用于本模型。

## 参数依据与已检查范围

质量来自厂家标称电机质量、现有外壳/脚底网格积分，以及逐件列明的电池、框架、PCB、线束预留。惯量来自相应体积积分或明确的均匀盒/圆柱估计，通过平行轴定理汇总；**训练 MJCF 不含早期静力脚本的人造惯量正则项**。实际转子惯量折算进关节 armature；例如 AK45-36 的转子数据按减速比平方折算约 0.02357 kg·m²。

7 个姿态 × 3 个质量变体 × 3 个 ±2N/0 拖拽工况，共 63 个静力工况，包含 50g 等效物体和局部 50N 嘴部反力。接触的正压力、支持多边形和摩擦锥线性约束均检查；静力矩与独立 MuJoCo 重力/Jacobian 计算一致。姿态涵盖站立、下蹲 40/60/80mm、低位够地以及左右单脚换重心。**这是静力与姿态筛查，不是动态步态、真实咬合或负载拖行证明。**

所有 18 个电机本体在这 7 个姿态下另做实体相交筛查，绕开仿真相邻刚体碰撞排除规则，未检出本体互穿；仍不涵盖插头、线束、螺钉和实物公差。支架还做了按双片均分弯矩的弱轴截面初筛；紧固连接、开孔应力、疲劳和跌落不能据此放行。

腿部最坏静态力矩约 5.92 N·m，对应主要腿关节公开额定 8 N·m，本版取 6.4 N·m 连续设计限值和 12 N·m 短时限值。不同关节参数逐项列在契约中。限速/力矩曲线、2 秒平方力矩预算和 350W 正机械功率上限均为明确的控制设计；平方力矩预算不是已经辨识的热模型。

运行期的头颈重力补偿只读取关节编码器与 IMU 方向，使用固定名义参数；没有读取随机化后的真实质量或接触力。其独立 NumPy 实现与 MuJoCo 重力项交叉核对通过，便于其他引擎重现。

## Sai_Lab 接入

解压交接包后保留目录。使用已安装 MuJoCo/PyTorch/RSL 的 Python 3.12 环境，在包根执行：

```bash
PYTHONPATH=src python scripts/training/train_goose_stage_one.py --output artifacts/first_run --iterations 2 --envs 4 --horizon 16 --device cuda
```

无 CUDA 时改 `--device cpu`。输出目录须不存在，防止覆盖已有实验。训练入口将模型和契约复制到该实验目录并校验哈希；实际长期 PPO 由 Sai_Lab 在这份入口上展开。策略目标当前是平地速度命令和本体平衡，不含视觉识别、完整抓取/拖拽任务奖励。**先做两轮烟雾检查，再自行安排训练预算；本工程阶段不追逐 PPO 收敛。**

本轮 DGX 的已完成 PPO 记录仅证明训练/检查点/ONNX 链路，记录中的输入快照和哈希是当时的候选；后续参数收敛会改变哈希。它们不是本版可部署行走策略，也不会作为默认策略塞入交接包。

标准轴序、SI 单位和观察/动作定义保存在 JSON；Godot/Jolt、Unity、Bevy 应从这份契约实现相同驱动与碰撞排除。结构 JSON 给出了坐标转换矩阵和极向量/轴向量转换规则。**MJCF/URDF 运动学一致不等于三套引擎动力学已验证。** 接入时首先核对关节正方向、静态重心、无支撑下落、足底接触、驱动饱和及更新周期，之后再做策略互放。

## 后续改动必须守住的边界

| 后续改动 | 对这份基线的处理 |
|---|---|
| PCB 走线、焊点、孔位、局部筋、非承力外饰 | 可延期；必须仍满足对应刚体的质量/重心/惯量范围、器件净空及结构承力要求 |
| 电池、框架或电机位置变化 | 重新计算分体惯量和整机重心，逐项比较契约范围；总重量相同也不能直接判定兼容 |
| 质量/摩擦/强度/延迟在随机化范围内 | 可继续同版策略实验，但仍需独立保留工况验证；随机化不是实物转移保证 |
| 关节数、轴线、符号、主要轴距、接触轮廓、执行器家族或传动比变化 | 提升版本号，重导模型并重验；必要时重训，不能仅改文档数字 |
| 超出任何参数预算 | 明确退出当前基线，说明改动及影响，禁止静默覆盖旧模型/策略 |

目前训练随机化覆盖逐体质量区间、躯干 COM ±5mm/其他刚体 ±3mm、惯量附加系数 0.8–1.2、摩擦 0.45–0.9、输出强度 0.85–1.0，以及 0/20ms 策略延迟。这些是**声明的实验/设计包络**，不是“行业通用 Sim2Real 允许误差”。后续样机测量必须回填实值；经过对应极端工况和跨引擎验证才有转移可信度。

## 明确未通过 / 需要下一阶段处理

1. **嘴部传动与持续夹持**：3:1 仍为候选，80mm 力臂下 50N 需要约 4N·m，超过当前嘴部 3.5N·m 连续设计值。模型允许短时 4.7N·m，但齿轮、轴承、实际热持续能力尚未闭合；不能称为真鹅咬合力已实现。后续方案必须守住头部质量和空间预算，否则重发基线。
2. **低位拾取控制**：几何和静力可达；单纯关节角插值的自由根试验会提前触地。需要带足底/末端状态的轨迹与反馈，不能据此宣布已经捡起地面物体。当前检查保留失败。
3. **供电配套**：电池尺寸/质量有公开候选，5V/12V 支路留有空间和质量；所选小型 AK48 驱动的具体工作电压窗口、回馈能量处理和保护仍需确认。公开通用 V3 手册所列其他驱动的 18–52V 不能直接套用到这些小驱动。
4. **制造与实物**：框架固定、薄壳开孔、线束接头、防夹、热与材料实测仍未验收。可延后雕琢外观/孔位，但不能把它们的未验状态隐藏为“已可直接打印装配”。

**判断：可以把这个明确版本交给 Sai_Lab 开始初训和接口接入；暂不承诺之后完全不会改结构，也不宣布硬件硬冻结已通过。** 本轮按 90 分钟窗口提交阶段成果并停止，下一轮从上面四项回到整机处理。
