# 任务驱动设计与仿真交接

## 任务与证据梯级

| 阶段 | 任务 | 需要的整机证据 |
|---|---|---|
| 布局筛查 | 自然站姿、胸前持物、前伸、低位触达、侧向门把操作、持物单脚换重心 | FK、轴限位、组件空间、COM、足底支撑、接触静力力矩和非相邻碰撞 |
| 身体基准 | 自由根站立、行走、转向、停止、下蹲和恢复 | 力矩/速度限值下独立动力学回放；明确持续时间与扰动范围 |
| 真实操作 | 进入抓取开口、闭合、抬起、搬移、释放及退出 | 有质量/摩擦的实际物体接触、夹持和承力链；力代理只支持局部静力结论 |
| 移动操作 | A 到 B 持物行走、转向、放置 | A/B 超出原地伸手范围，抓取和步行的组合任务独立验收 |
| 环境操作 | 绕障、开门、简单工具，组合成长任务 | 目标/障碍变化、重新观察、失败重规划与可复现多次任务 |

首轮载荷试探为 0/10/20/40/60 kg，属于**扫描输入**。不能把 60 kg 写成已经承诺的额定载荷。最终建议来自几何、静力、接触、结构、持续驱动/热的共同可行范围；缺少后几层时只给计算需求与假设范围。

主视角必须检查胸楔遮挡；近距腕部视角是候选。保留中央橙色灯的外观身份。宽体和持物扫掠包络决定游戏通道、工作台、门和目标物尺寸，不能只按根节点半径规划，也不能缩放机器人迎合场景。

## 最小物理接口

本候选使用 SI，前 +X、左 +Y、上 +Z。模型需要同版导出：父子树、每轴位置/方向/正方向/限位、具名关节顺序、逐体质量/COM/完整惯量、驱动设计值与未识别项、接触近似、传感器位姿/视锥和控制时序。

主动关节、自由根与被动机构分别计数。47 轴是布局候选，不能填入 G1 的 43 轴策略或 Goose 的观测/动作维度。此轮只输出具名物理关节及加载接口；学习策略的观测归一化和动作合同在本体稳定及选择控制路线后独立定义。

Bevy 目标沿用已核实的 50 Hz/20 ms/一次积分。MuJoCo 2 ms 是独立诊断设置；其成功不能替代 Bevy 20 ms 接触和驱动通过。相同 SI 本体通过坐标和驱动适配进入各引擎，每个后端独立加载/回放。

## 后续自主闭环

自然语言目标 → 本地视觉认知与任务决策 → 经验证技能/VLA → 全身控制 → Bevy/Rapier 原生物理 → 同版相机/状态反馈 → 完成判断或重规划。

机器人、物体和环境必须处于一个权威物理世界。物体移动来自真实接触和驱动。目标身份来自感知/公开标记；独立验收器可读取真值，但答案不能泄漏给正式感知决策。布局/控制诊断使用真值时显式标记 oracle。

观测和命令需要机器人/模型版本、episode、tick 和时间戳；重置清空旧图像、请求、历史和动作。技能具有前置条件、执行状态、成功条件与失败反馈。超时/目标消失/动作越界执行经验证的停止或明确暂停；安全停止不能计为任务成功。

最终至少分别进行多初态的静态取放和 A→B 搬运重复测试，报告成功数/总数、种子、失败类型、仿真与墙钟时间和实时性。释放后稳定受支撑、机器人未跌倒才计放置成功。环境变化和服务故障另测。借鉴 G1 的闭环架构与验收经验，不把其尚未完成的 Bevy 结果当作 Gorilla 的验证证据。
