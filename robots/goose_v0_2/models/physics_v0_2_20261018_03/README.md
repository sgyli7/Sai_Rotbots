# Goose V0.2 · physics_v0_2_20261018_03 — 14 块碰撞代理

本版只替换碰撞代理。硬件物理与执行器合同逐字继承02；版本03不代表新的质量或执行器能力。02保留为历史版本，03的接触验证独立执行。

本目录是独立训练物理数据包。以实际 whole05 和明确的工程质量分配冻结 **16.97020392883353 kg、23 刚体、18 个控制轴、4 个内部机械坐标**。它不表示实体机器人已加工、装配或完成任务训练。

安装 `requirements.txt` 后，可以直接在解包目录运行：

```sh
python verify_package.py .
python runtime_adapter.py . --steps 5
```

`robot.xml` 及 `meshes/` 是 MuJoCo 入口；`physical_contract.json` 保存逐体质量、重心、完整惯量、轴、限位和内部机构；`actuator_contract.json` 保存每轴连续/峰值扭矩、速度、损耗、曲线和功率假设；`mass_ledger.json` 保存逐项来源与工程预算。运行仅依赖本包文件。JSON 中的历史工程路径仅用于追源，不作为运行资源地址。

参考入口为包内 `runtime_adapter.FrozenPhysics`：

```python
from runtime_adapter import FrozenPhysics
robot = FrozenPhysics('.', bus_voltage_v=22.2)
state = robot.step([0.0] * 18)  # 一个50Hz策略周期，四个200Hz驱动/物理更新
```

18 个输入是按 `joint_order` 排列的归一关节位置目标，先夹到 [-1,1]，再转目标角、按限位和最大速度做目标斜坡。参考适配器每 5 ms 计算 PD、连续限矩、扭矩速度包络和 350 W 总正机械功率预算，然后输入实际电机/输入转子的18个 effort motor；每次 `step` 共推进20 ms。内部四杆与两个髋偏航传动由模型约束参与动力学，只在 reset 初始化内部坐标，不在步进中投影坐标或施加根部支撑。

默认持续能力为 AK45-36 6.4 Nm、AK40-10 1.04 Nm、AK45-10 2 Nm、头侧倾0.14 Nm、嘴4.4 Nm；每轴实际表为准。原生 XML 的 ctrlrange/forcerange 同时按持续能力硬限幅。峰值能力单独列出，默认禁用；未实现峰值时长或热模型。直接加载 XML 的训练端仍须消费参考适配器的200Hz目标斜坡、速度曲线和总功率限制，不能将 XML 的固定限矩误认为已经实现全部供电约束。

主电池默认22.2 V，允许设计窗口20–25.2 V；曲线参考24 V。低于24 V时速度轴和目标斜坡按 V/24 缩放，高于24 V不增加性能。XC330-M288-T使用独立5 V分支，不随主电池缩放。350 W是每个驱动更新时刻的总正机械功率设计预算，未模拟电流、效率、压降瞬态、再生制动或温升。头侧倾损耗0.036 Nm＝原0.006＋CRBT新增0.03，只计一次。

`observations()`可提供65维常见物理观测布局，仅包含关节状态、根部姿态/角速度、调用方传入命令、上一动作与相位。包不包含任务奖励、终止条件、策略或训练代码，Sai Lab 可自行映射训练接口。完整 MuJoCo 状态有7个浮基位置分量和22个铰接坐标；18维策略顺序不等于 qpos 的连续切片。按 `runtime_interface.json` 的名字映射读取，不能套用旧模型的数组下标。

**接入旧 Goose 时注意根坐标：** 本包的 torso 根原点是原CAD地面参考，冷启动根高度约5.5 mm，躯干/整机重心仍在实际机身内。因此 `qpos[2]` 不是旧模型约290 mm的身体高度；需要物理整机重心高度时读取 `data.subtree_com[model.body("torso").id, 2]`。不要把旧 root高度阈值不经映射直接用于新模型。接触形状按名字和owner读取，数量/索引由本版清单明确，不复用旧11/14/22叶的硬编码。

电气未完成安装的预算均有明确刚体归属、质量、区域和完整惯量。新脚原始八件和 head17 未装通方案未采用；保留正确旧六件脚部机械回退和原脚底接触。实体制造与热/疲劳/称重/装配、外观一比一及任务能力仍是独立工作，见机器人导航中的硬件续办索引。

原喙传动的0.85效率属于选定4.4 Nm设计限矩的规划依据，参考适配器不另外乘一次效率；实际动力学使用明确的转子惯量、关节摩擦和阻尼，不伪称已经校准齿轮效率。速度上限用于目标斜坡和电机曲线，并不投影或夹断被外力反驱的实际关节速度。

接触叶数量、支持顶点、实际步进成本、数值检查与独立解包结论，以配套验证结果为准。不能把模型加载成功或短步进当作移动、起身、抓取任务已经完成。

后续硬件须服从本包冻结的质量分布、惯量、轴系、外接触及功率合同。需要改变时发布新物理版本，保留此包，不热覆盖。

本版实际编译 **14 个凸碰撞块、544 个凸支持顶点、每块最多63点、1032个凸三角面**。这些来自 MuJoCo `mesh_graph`，不是语义分组数量，也没有把加载网格顶点误当凸支持数。完整逐块OBJ哈希在 `collision_manifest.json`，全部运行资源均为包内相对路径。

14块分工为躯干2、颈部2、头部与上喙1、下喙1、左右髋连接2、左右大腿2、左右小腿2、左右脚2。头俯仰外皮和踝部近轴圆罩采用相邻外部角色近似，内部安装孔和机械腔不逐面复制；逐体质量与惯量始终来自原硬件合同，绝不由这些粗代理体积计算。

原生直接父子过滤之外，仅有6对显式机械相邻例外：`torso–neck_pitch`、`torso–left/right_hip_roll`、`neck_mid_pitch–head_roll`、同侧 `knee_pitch–ankle_roll`。它们之间只跨无外部碰撞几何的内部轴载体。头–身、躯干–大腿/小腿、左右肢体仍参与接触；上下真实喙面通过显式接触对保留闭合止挡。独立检查会核对全部其他跨角色组合，没有全关节自碰豁免。

有限接触夹具覆盖四个完整颈部反配重姿态、左右髋俯仰+0.7弧度的身体–小腿阳性、交叉脚阳性、双脚底地面，以及真实50g、20×20×16mm物体的嘴部开口与上下接触。首次候选漏检右髋阳性已被拒绝；本版只调整原躯干块侧面轮廓修复，不增块。这里的通过不等于全ROM无干涉或移动、起身、抓取任务已训练成功。

普通训练轮廓允许近似。零位有限采样中，脚底1440方向的最大支撑缩入0.5224mm；整机54方向最大斜向缩入2.4315mm，躯干局部为6.9954mm；六坐标轴极值保持。上述是有限支撑方向检查，不是全表面或全关节空间误差保证。关键脚底平面、嘴部物体空间与非相邻碰撞另外验收。

**性能限定：** 同CPU、MuJoCo3.10的有限重复测量，新14块碰撞约7.15–9.07微秒，原生整步约32–42微秒。对真实旧Move14参考的静态碰撞成本仍为约1.85–2.05倍，未达到事前建议的1.5倍目标；该性能门保持REJECT，经理接受它作为有明确边界的低复杂度训练参考。对相同新硬件291块模型，10姿态重复测量碰撞快42.76–67.29倍、原生整步快9.56–13.47倍。新旧整机还有23/21刚体、3/1闭环和76/67启用接触角色对等差异，不能将所有整步差异归因于碰撞。GPU和批量训练性能未测试。
