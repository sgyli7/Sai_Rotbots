# 大型 Goose 资产的拉取

GitHub 交付快照使用 Git LFS 保存超过 100 MiB 的 Blender/OBJ 文件。LFS 指针保存原文件的 SHA256 和长度；CAD、图片、采购表及普通源文件仍位于原目录，未删减或改名。

在安装 Git LFS 的机器上拉取交付分支后执行：

```bash
git lfs install --local
git lfs pull
git lfs fsck
```

未拉取 LFS 时，对应文件是三行文本指针，不能直接拿来加载 Blender 或仿真。工程参数、验证证据中的 SHA256 均指展开后的原始资产，不是指针文本的哈希。
