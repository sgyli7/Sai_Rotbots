# F 旋转液压短节备选：有界一手核查

本分支仅做宏观器件与包装筛查，不代表 root 选定替换。此前 E2a fold5284Nm / ankle4914Nm 只作两处失败候选的敏感输入，不升级为新本体最低需求。未改 F1/E2a 的模型、配置、结构、排期或任何受控文件。

直接照搬目录最大 L10/L20 或 L30-42 不能满足这两个**运动**敏感点；L30-65 有更高运动力矩参照，但完整长度与法兰直径明显超过原视觉短节量级，且单件目录约108.9kg。此路线可以提供真实螺旋花键传动/输出支承标尺，不能被称为已经解决短节设计。

L30-42/65目录悬臂弯矩参照分别11865/18363Nm，180°双端支承分别30849/47799Nm；这些是外载支承参照而非附加驱动力矩，实际轴承反力、安装桥和动态寿命仍未核。L30 FF版没有缩短总长。FF42输出12×M20×2.5深30/PCD150、壳法兰12×M16/PCD245；FF65输出12×M22×2.5深33/PCD170、壳法兰12×M20/PCD275。L20-39浏览提取的壳径同时出现7.75in和191mm，前者自行换算196.85mm；尚不能确定是PDF原排印还是提取错误，不能用较小数字作为权威制造尺寸。完整装配公差/阀管凸出与CAD仍未知。

同目录p4表示运动力矩随弯矩可能降低约15%；p7的其他L30阀参照pilot2.5:1、relief250±25bar，较小特定版本不同。公开入口指向工厂请求CAD，本轮未得到完整CAD，也未发送请求或提交表单。额定曲线的角速度、油温、持续/占空比与机器人重复热条件未公开闭合；207bar目录工作参照不得靠315bar服务试验提升。

自锁必须保留证据冲突：[型号专属L10官方HY34-1001-B1 p1](https://www.parker.com/content/dam/Parker-com/Literature/Industrial-Cylinder/Helac/PDF-files/Helac_Series_L10_Flyer_HY34-1001-B1.pdf)明确非自锁；[L30服务手册HY34-1130 pp32–34](https://www.parker.com/content/dam/Parker-com/Literature/Industrial-Cylinder/Helac/PDF-files/Helac_Series_L30_Service_Manual_HY34-1130.pdf)说明打开压力口后可撬杆手转，也列阀/密封泄漏、气体导致不能保持。其315bar是泄漏/裂纹测试。较通用[官方白皮书p5](https://www.parker.com/content/dam/parker/msg/motion-systems-group-europe/landing-pages/hydraulic-actuation/WP-rotary-actuator-vs-cylinder.pdf)却写机械自锁；本分支采用型号/服务证据限制，不据通用宣传删除制动或失效保险。counterbalance的断管保持、过中心与过载释放功能必须结合实际阀、封闭油路、回压/先导压力和故障模式，未证明机器人安全停止。

以下是**自行计算**，不是另一个厂家额定：`Tref(204)=Tcatalog×204/207`；仅作额外敏感项乘0.85，不能当已验证降额下界。分别得到运动参照（无弯矩惩罚 / 15%惩罚）：L10-25 2784.1/2366.4Nm；L20-39 4343.1/3691.7Nm；L30-42 4677.2/3975.6Nm；L30-65 7238.6/6152.8Nm。前3项仍小于5284和4914，即使暂忽略阀损也失败；第四项只是名义力矩量级可覆盖，持续与包装未过。

排量公式 `Qgeom=V180/π×|ω|×60`（L/min）给 L30-65 在0.1/0.3/0.5rad/s时3.568/10.703/17.839L/min，四轴同时0.3约42.814L/min，仅本四器件目录质量435.6kg。204bar×Q/600对应每轴1.213/3.639/6.065kW液压功率尺度，不能全部称有用轴功率；真实损耗曲线、节流、回压、负功与回馈/卸荷未核。ω=0给几何流量0，只说明位移停止，不说明泄漏、待机泵或热功率为0。

同粗模型在15%弯矩敏感项下，5284/4914Nm分别需约175.20/162.93bar的有效压差；204bar供应余量还须支付双计量边、保持阀、管线和回压，不能认定可同时达到目标速度。若仅对比历史最大轴向窗口308mm和视觉轴座直径170mm，则L30-65长超105mm、FF法兰超145mm、壳径超33mm；这是**给定窗口的一维下界诊断**，未做同源原生模型布置/碰撞。可考虑近端/跨节安排才有研究意义，不能硬塞后称短节完成，root负责最终路径与形体判断。
