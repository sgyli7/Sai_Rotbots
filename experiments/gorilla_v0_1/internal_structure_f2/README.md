腰髋原源有 16 行相同 ID 的重复缸上下文：515/519 行实际只有 499/503 个唯一 ID，作为资源失败保留。最终 v3 撤回初版将微小退化四面体误判内腔的结论；有效原生闭面与导入来源一致，复核真实冲突仍成立。限定材料与 24 个完整部件参考分别计量，不能将工业参考包络当精确材料或据 owner 名称证明承力连接。

压力报告只按实际顶点尺寸及声明工况做解析粗筛。理想闭端直筒 VM 142.524 MPa；轴向路径改变的敏感点为 155.142 / 187.981 MPa。真实叉面反力跨度 50/64/78 mm 与眼分布/点载给出的销弯剪非同点包络最大 211.881 MPa；这不是真实接触某点应力或能力保证。材料标尺 Ovako 6082 是厂家 42CrMo4 M 钢系列代码，不能与 EN AW-6082 铝混淆。全机力分配、动态、热、供电和回馈均未在本模块成立。

## 主线程独立修正

[F1 原生边界检查](root_audit/f1_native_boundary_nesting.json)直接检查 375 件源，不修法线。四块脚托盘有正向封闭内皮；[局部诊断](root_audit/f1_closed_cavity_diagnostic.json)及保存的面方向补丁只修这四件，受影响材料组分析差额 −13.527 kg，不是新完整账本或减重收益。`Manifold.compose` 会丢弃负内皮，不能用于此修正；直接拼接有符号 Mesh64 的空心箱回归经过实际验证。

[上游追溯](root_audit/e2a_inherited_foot_boundary_warning.json)确认 E2a 同名四件的顶点和面与 F1 完全一致。E2a 旧完整库存、旧质量/静力数值仍保留历史源含义；它们没有得到物理材料资格。F1 的 650.3295 kg 幽灵库存更正和文件/导出身份检查仍在其原范围有效，但原材料质量及连通数不能作为合格本体证据。没有改写任何旧冻结源，也没有据局部补丁重评级整机。
