实际资源检查覆盖667新成员；限定新成员/111甲/128肩筛查仍有317正交对，不代表检查了全部2538件。两驱动case各64.211cm³穿框，保护减速器参考体和固定holder也穿框；油库存碰腿甲、水库存碰socket。锚座与框重叠不自动成为合格焊接实体。安装梁留1mm断隙，电芯到冷板10.925mm间隙及冷板无连通接口仍拒绝。原生[四视](torso_system_colayout/b/native_four_view.png)、[去甲上下文](torso_system_colayout/b/native_cutaway_four_view.png)和[真实截面](torso_system_colayout/b/actual_sections.png)已查看；去甲图不冒充实体剖切或美术验收。

## 格栅和热路

[G11错误面积已撤销；G12按实际原甲重核](thermal_route/README.md)。两格栅去除实际百叶投影后净投影面积合计0.03223205m²，仍未计过滤器/护网/其他遮挡。真实喉段和转角plenum未密封到环境出口。

采用[ebm-papst原厂风机曲线](https://www.ebmpapst.com/content/dam/ebm-papst/products/compact-fans/axial-compact-fans/DC_axial_compact_fans_catalog.pdf)同一工作点及[Boyd4320原厂热曲线](https://info.boydcorp.com/hubfs/Thermal/Liquid-Cooling/Boyd-4320-Heat-Exchanger-Graph-Metric.pdf)，没有混用零压最大风量和耗电。Boyd纵轴是Q/(进水温−进气温)，不能称UA。完整芯尺寸/安装、风机安装与实际液路仍未闭。

A条件7.711kW前端全热在25°C环境、双完整芯各7.5L/min、空气升15K时需要0.426m³/s，净投影风速约13.22m/s；尚允许的未知压损K仅约2.7–3.1，原风道未证实。480芯典型内阻条件替换总效率热后A约8.010–8.991kW，紧工况K余量约0.36–0.41。B12.759kW升15K流量超过风机范围；升25K的回水仍约60.9°C，超过参考电机LC进水50°C限制。不能宣称现有双格栅已足够。

候选路线为前格栅低温回路＋隐藏侧/后高温油回路，或重做隐藏密封风道/完整芯与风机。3kW前环只是待分配设计问题，35°C环境示例回水52.9°C仍拒绝；新排风、油水HX/泵和安装尚无CAD。39项数值核只支持算术，图像/源身份不批准热能力。实际原生ROI和原厂曲线已查看。
