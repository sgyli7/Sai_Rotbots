# G22 common core connection probe

One actual, rejected connection source is frozen. `module_scene.json.gz` contains 251 members: 28 newly generated material pieces, left/right complete G21 joint context with the exact fixed receiver replaced once per side, and five unqualified existing waist components. Original G21 sources were not modified. The right source is an explicit mirrored export with corresponding winding reversal, not repaired input. No visible armor or exterior geometry was changed.

The new frame uses the existing wide 200×80×5 mm rails, replaces the failed narrow shoulder strip with a real X=.115 matched plate, 54×60×6 mm closed transverse bridge pair, and an eight-hole M12 proxy pattern. Derived receivers contain matching holes, actual backing bosses and a full controller clearance window. The cage waist face is truly X=.228; an eight-hole PCD220 mm conditional output mating ring was generated. Existing rotating waist output hardware is absent. A fixed gear load shell is not relabelled as output.

All 28 new native parts pass signed closed-material and single-root resource tests. Assembly fails: 21 new/new positive overlaps and 74 touching-new pairs remain. Independently classified, 60 are between valid native material resources, two involve unqualified material resources, and 12 are complete reference installation obstacles. Source finite roles plus explicit density were checked, so old waist parts without the `finite_material` Boolean are not silently ignored. Four retained roll/yaw receiver resources remain invalid. Same-owner overlap is never exempt.

Matched shoulder projected material area is about 48,694 mm² per side, but frame/receiver overlap remains 17.3814 cm³ per side. The new conditional waist ring intersects the solid neck by 71.0599 cm³. Existing waist cooling case, input hub and fixed gear shell also conflict by 48.0883, 40.7242 and 30.8328 cm³. Bolt heads intersect actual bridge/cage stock. Therefore area/holes/coaxial position do not qualify mating, torque transmission or installation. Geometry was locked after this first candidate; the failed parts were not shaved or relabelled to pass.

Own new individual-piece material inventory is 221.8597 kg, including shared frame 134.2934 kg once, two steel derived receivers 40.6007 kg each, new conditional waist ring 4.9414 kg, and all 24 fasteners 1.4236 kg. This sum is not assembled net mass: intersecting stock is not subtracted as a fictitious credit. It excludes catalogue component mass/COM/inertia and the rest of the robot. Receiver geometry changes −8.610 cm³ relative to the same native source. Most receiver mass increase is the explicit 2700→7850 kg/m³ material hypothesis, not a larger volume: −0.02325 kg geometry contribution at old density and +26.6361 kg material contribution per side. Original exact-CAD 13.9942 kg must not be mixed with original native 13.9878 kg. Same new geometry at2700 would be13.9646 kg with E69 GPa sensitivity; this was not adopted or credited as a strength result.

`literal_sections.json` and `literal_node_and_bolt_screen.json` derive actual source contours and nominal6D bolt-group algebra. The independent 3t compression fixture is not hand payload or gait/selfweight rating. For its1.5 wrench the waist proxy shank reaches244.65 MPa before actual thread area, preload, contact, prying or fatigue; the235 MPa steel comparison is only an explicit hypothesis. Actual shoulder wrench must be supplied through the saved geometric6D transfer from the new pitch axis to the real hole centroid. Three discrete source-joint display poses retain all context; they are not continuous motion or dynamics validation.

`common_core_si.step` is the exact OCP shared frame with explicit metre declaration and independent SI readback; relative volume error is about−2.33e−14. The numeric-original STEP and BREP remain preserved. Derived receiver/other-piece manufacturing CAD is not claimed. Native same-scale fourviews and actual contour sections were viewed directly. They are local mechanical diagnostics, not an AA3 replacement aesthetic image.

Reproduction uses existing `.venv/bin/python`: `build_connection.py`, `check_connection.py`, `supplement_material_scope.py`, `render_connection.py`, `final_evidence.py`, `freeze_connection.py`. There is one geometry layout. No new fullbody, exterior, FE/PPO/GPU/Git or source repair was performed. The next macro must jointly rebuild the pitch input socket/load rail and real waist output interface, rather than adding isolated patches to this failed candidate.
