## 宏观计算及真实接口

逐ID绑定的条件干库存子集中，A为707.710/819.189/995.718 kg，B为671.151/782.631/959.159 kg。它们只是633个有质量范围及未合格COM代理的上部候选行；油水、输出拆分、保留adapter、未覆盖成员、实际任务及运动仍缺。**不是完整上部或整机质量/惯量。** 工业驱动库存、承力壳、热/液压及安装辅助均有显著贡献，不能把减重全部压给骨架。只变换本次实际摆位和候选owner后，布局1/2相同选定行干小计约770.557 kg，仍是有限敏感性；将HX改挂pelvis不是删除其整机功能或质量。

根线程独立用`F=(0,0,-mg)`、`M=(COM-pivot)×F`复核了全部选定行、A/B替换及两实际变换，详见[root算术复核](root_review/upper_subset_arithmetic_review.json)。历史腰roll位[0.23,0,1.91]上的B干子集横向翻转My约2.47 kNm；两新布局约2.35–2.40 kNm。左右近似对称使roll轴Mx接近零，不能据此省掉双侧支承、固定壳或弯矩核查。

腰旧adapter半径80/30 mm，新boss100/40 mm，共面几何最大环带r40–80 mm约0.01508 m²；整个标签平面不是实际接触面积。新肩候选轴Z2.29与旧stock驱动Z2.36相差70 mm，旧gear123.5 mm长度还存在已知8.5 mm错误；新core与旧gear包络相交不能证明正确安装后仍相交，更不能据此要求AA3改形。下一步重建115 mm完整驱动、真实固定/输出接口及传力壳，保留未核datum、连接/额定红线。
