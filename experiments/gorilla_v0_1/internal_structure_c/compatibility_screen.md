# 内部 C：RV-N 与 QTL230 的有限兼容筛查

状态：只做组件代数筛查；不选定架构，不作关节／整机放行。输入取自已核读的 [受控组件资料](../../robots/gorilla_v0_1/hardware/compact_electric_component_references.md)，本轮不改该文件。核算日期 2026-10-02 UTC；JSON 为 [compatibility_screen_calculation.json](compatibility_screen_calculation.json)。

比较输入 `Tout` 分别取 RV160 的 1,600 N·m、RV380 的 3,724 N·m **目录额定力矩**；它们不是 Gorilla 的逐轴需求或 C 的目标性能。其他需求可用 JSON 的每 1,000 N·m 系数线性代入，但不能因此获得资格。输出轴转动固定采用 RV160 R=41／81、RV380 R=75／117；未改成外壳转动速比。

## 1. 方法和判定边界

`n_motor = ω_out * R * 60/(2π)`，`T_motor = Tout/(η*R)`。η=0.70 仅为 Nabtesco 目录输入功率计算参考；0.55／0.85 是主线程要求的敏感性假设，**未证明它们夹住真实效率**。静止时该效率式只是指定代数比较，不能代替静态摩擦、反驱、机械制动或真实保持力矩模型。

ω=0 使用电机连续堵转 Ts；ω>0 对照连续旋转 Tc，但本轮缺实际转速的完整 T–n 曲线。超过 Ts／Tc 则拒绝该名义比较点；未超过仅表示未触发这一条拒绝，不能判 PASS。没有使用峰值补持续缺口。

QTL230-65-N：Ts=48、Tc=67 N·m，6.8 kg；85-N：Ts=76、Tc=107 N·m，9.6 kg。原厂连续条件为绕组100°C、安装面20°C。709／451 rpm 是 **680 Vdc 上限下、Tc 力矩时的 nmax 点**，不是低负载通用速度极限。实际母线尚未选定，本稿没有带入102.4 V。

出处：[Nabtesco catalogue，印刷 p7–9、22–23／PDF p9–11、14–15](https://www.nabtesco.de/fileadmin/04_Service/05_Downloads/01_Produktkataloge/RV-N_catalogue_EN.pdf)、[QTL230 EN 2.4，性能 p1／尺寸 p2](https://www.tecnotion.com/wp-content/uploads/2025/11/QTL230_Specsheet_EN_2.4.pdf)。
