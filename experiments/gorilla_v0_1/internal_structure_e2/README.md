# Gorilla E2a：串联内部候选与拒绝证据

当前候选为 E2a，整机源 SHA-256 `6039922d1ab479346dd590745b78d5e176a8ecf6a039bc734cfbfeed686516f6`。**未通过装配、物理、审美或稳定 SI 门禁，首个检查点仍未达标。** AA3 仍是唯一外观权威；原比例、高度 2.65 m、111 件 C15 护甲和 4 主接地垫原样保留。本轮没有批准或发布新的外观基准。

实际候选包含串联腰/髋/腿/脚、14 臂轴载体、18 个有限液压缸、分布式电驱参考组件、保持/卸荷模块、油水换热器和供回路。13 液压轴、18 电驱轴及 16 手部预留是探索拓扑，手部完整机构未选定，51 个树节点/47 个主动轴标签不能当稳定 action contract。前后掌仍分段；原 2 片前掌上缘被实际钢支承替换，没有连续板跨越前后掌铰链。

## 冻结和复现

[snapshot_manifest.json](snapshot_manifest.json)列出原路径、储存和解压 SHA、既有输入身份。大 JSON/Blend/GLB 采用 `gzip mtime=0`，脚本以 `.py.txt` 保存为实验输入；Blender 和 GLB 解压后可编辑/加载。OEM 参数引用和版本在原 spec/manifest 中，第三方下载 PDF 不入库。上游两项历史绑定问题见 [provenance_exceptions.json](provenance_exceptions.json)，不宣称递归所有旧输入可逐字重建。

在独立 checkout 使用已有 `.venv` 环境恢复；恢复脚本遇到不同内容拒绝覆盖：

```bash
python experiments/gorilla_v0_1/internal_structure_e2/restore_snapshot.py.txt --root /absolute/path/to/checkout
.venv/bin/python .scratch/gorilla_e2a_right_hip_inventory.py
.venv/bin/python .scratch/gorilla_e2a_integrate.py
.venv/bin/python .scratch/gorilla_e2a_statics.py
.venv/bin/python .scratch/gorilla_e2a_render.py --resolution 700 --samples 32 --views front,left,rear,top,cutaway_front,cutaway_left
.venv/bin/python .scratch/gorilla_e2a_resource_audit.py
```

直接冻结输入用于实际 E2a 重建；旧上游 builder 仅为原始记录，不应在恢复后随意重跑并覆盖冻结 system/structure。独立审计见 `independent_audit/`，原几何与六件补齐分别列范围。本轮仅新增设计/实验资料，没有修改运行代码、模型 contract 或策略；此前软件回归不能关闭上述红线。本候选只推送草稿 PR，不因资料已提交而合主干。
