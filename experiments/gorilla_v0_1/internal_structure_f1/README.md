## 物理结果

结构净有限钢假设约 772.656 kg；另有完整组件/轴承等参考 107.693 / 123.213 / 154.013 kg。这是**列出结构范围**，不是全机或减重结果。新阀模块干质量约 184.623 / 213.059 / 246.008 kg，另有保留系统和不相容上下肢上下文；缺四缸、重复功能的肩反力桥、真实流体位置和惯量仍未闭合，不能将所有账本简单相加宣布整机净重。

中立不同材料组 180 对正体积交与系统两布局 1781 / 1778 对占位交属于不同筛查范围，不能相加成全机冲突总数。OEM 完整外包络相交另列不确定安装资格，不默认扣出不存在的内部空腔。材料连通统计须区分实体与封闭内腔表面：原 `trimesh.split` 表面岛计数保留历史含义，由独立审计修正文义；不能据此自动判定真实断链或通过。

**账本更正：** 原系统账本有 142 条已移除结构的历史合并质量行，成员全部不在 F1 原生库存，合计 650.329499798 kg；不能因合并行 ID 不在移除名单而继续计数。更正后已列现存库存为 1840.372 / 2034.115 / 2327.041 kg，仍包含不相容肩支承、四个无安装主体的保持候选及未闭合功能，**不是完整机器人质量范围**，剔除错账也不是减重收益。实体连通更正为 134 组中 23 组多实体、总 182 个正外实体；负内腔归属与有符号体积守恒经过回归，质量不因此改变。

30 L 油库存只计一次；119 条新油路只有端点清单，8 个缺缸终端未知，全部未接通。旧画出管路与移动模块不再相连，旧 24 V 配电也不能直接满足 18 个 OBE 控制器。实际端点流量、阀的参考流量与压损、泵、供回压、负功去向和散热须在同一任务工作点闭合；本阶段没有新的性能评级。

下一步先共同设计完整短腿段及固定/输出分层的腰髋模块，消除真实装配问题，再接回全机。当前失败说明这些内部候选不成立，尚未证明 AA3 必须改形。确需外形变化时才给具体约束、改量和同源四视；用户认可后采用。
