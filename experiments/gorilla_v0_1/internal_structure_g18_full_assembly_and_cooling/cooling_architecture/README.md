# Gorilla G18：两种完整冷却架构的条件比较

本目录只交冷却架构、完整功能占位预算及可重算物理边界。最终入口为 `architecture_comparison_v3.json`，原 v1、各 producer 和官方缓存保留。G17 完全未改。没有改变 AA3 外表面、机械合同或任何其他 Agent 的源；没有采购、GPU、CFD 或整机额定放行。

**结论：分开 EMRAX 的敏感低温域能解除电芯／逆变器发热对其入口温度的耦合，也可取消两只低温泵串联。代价是两套完整换热包、第三独立排气和保护模块及更高辅助功耗。当前物理证据仍不足以放行任一整机方案。**

EMRAX 每支6 L/min是公开下限，不能把名义6当不平衡仍合格。另给同一B拓扑内13 L/min控制目标（每支6.5、假设误差5%后6.175）；真实流量反馈、冷液压降和保护尚未实现。这不新增第三架构。18自制板、4电池板及计算板的流量是设计问题，尚未成为器件要求或实测额定。

## 同工况热与能量

公开 ES 图是 **50/50 EGW 71.1°C** 的联合空气／水流点；0707新点为每只6或11.75 L/min、空气6.5 m³/min，均在图的1–5 gpm族内。0714使用10 L/min、整芯空气13 m³/min，英制纵轴按0.527527926转换。每只172风机承担自己的空气流，未把一只风机当整芯13。本轮没有把4320缩尺寸或按面积移植热能力。

冷温性质来自历史 DOW 50%EG典型表，ES流体实际配方、内部流态和流体热阻比例未知。`v2/v3`以平均液温迭代 ROM 参数，避免把35°C物性直接当50°C工作液的精确数据；这仍不是实测UA、完整εNTU模型或可信保证下界。

| 35°C环境／运动峰／B全部辅助输入上界 | 原30分钟任务占空 | 高并发敏感性 |
|---|---:|---:|
| EMRAX供液，条件ROM范围 | 41.40–46.85°C | 43.14–51.29°C |
| 其余供液，200V条件ROM范围 | 49.46–53.94°C | 62.97–69.11°C |
| 热回路供液，条件ROM范围 | 56.44–59.84°C | 67.56–72.15°C |

EMRAX公开额定入口≤50°C，因此高并发仍存在超限情况。电池、计算和自制板的允许入口温度分别未知，不能以EMRAX温度合适替代其门禁。QTL239mm条件板与QTR160mm板分列，未把大板的热阻赋给小板；QTL/QTR公开100°C绕组／20°C安装面条件没有因水温50–70°C自动保留。`same_task_TIM_boundary_by_water_temperature` 给各真实电机参考的任务转矩、铜损和所需总接触／冷板热阻；RMS、转速、铁损、再生及保持损耗仍未闭合。

LC约1/3只用于电机损耗，逆变器损耗始终保留在其余域。EMRAX转子空气需求按真实泵轴功率计算；原任务峰每只3 m³/min、高并发每只5.25。建议共享**两条其余冷板芯的空气支路**，剩余旁路重合流，转子热预热计入该域；敏感域13 m³/min保持新鲜空气。完整风道、分支压降、转子环流、排风和回流均未安装，不允许先领走此热分配收益。

`v3`另核同空气工作点：公开风机锚点622m³/h、475Pa、215W，经理论相似律到6.5m³/min约186.74Pa；这不是实测PWM点。敏感新鲜空气域假设总压损134.3–164.4Pa；两条共享转子支路125.0–215.1Pa，最坏较理论扬程短28.39Pa。其他低温支路110.0–140.1Pa，热路93.0–129.1Pa。实际密封风道／护网／前净开口未知，不能靠零静压流量或理论53W功率放行。原前开口只供两条新鲜敏感芯，共13m³/min，其余26及热13各自独立进排风；所有空气各计一次。

辅助总账一次计入：8风机公开电输入上界1.72 kW；WP32两只28V×15A为0.840 kW（32V上限敏感0.960）；热80为0.0975；其他0.500 kW为明确分配的未核任务预算。风机PWM理论功率没有用于补能量缺口。泵输入上界不是同12/47 L/min的实测输入，保守把其全输入作为水路热负荷；实际轴／壳散热需同工作点测量。HV/LV转换损耗仅通过0.98条件效率计一次。

B／28V辅助预算3.1575 kW下，原30分钟、480颗最低7.44 kWh、SOC窗75%、288→200V条件：

- 无额外储备需要8.2000–8.5222 kWh；保留10%储备需要9.1111–9.4691 kWh。
- 480颗／10%储备条件持续24.50–23.57分钟；32V功耗敏感23.32分钟最小。
- 在原占空和200V热电假设下，要30分钟且留10%储备，允许**全部辅助预算约0.7305 kW**。现有完整器件的真实PWM和泵效率图不足以证明这个值可达。

不承诺25／30分钟，不新增电芯、不减占空、不删热。高并发60分钟需求约35.52–38.30 kWh，480完全未闭。
