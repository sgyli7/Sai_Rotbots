## 联合热与压降

ES0707公开联合点是50/50 EGW71.1°C，每只液流11.356–18.927L/min、空气6–7m³/min，手读 H75–95W/K、液压降约23–42kPa（手读不保证上下界）。四芯需总45.424–75.708L/min，实际59基线每芯14.75。不能套用热曲线而忽略液流。ES0714 全芯空气10–14m³/min、液流7.571–11.356；手读 H105.5–165.1W/K，不把每个风机分配成全芯空气量。

EWP150公开图59L/min约38.84kPa；两串联同Q仅加head约77.68kPa，两并联则Q分摊、head不加。单150可能仍失败。以四米主路、f=.025、K4作可检验敏感性，18/25/32mm内径与冷板/分路所需head分别列在JSON；原肩4mm接口3.3L/min的19–77kPa挑战仍存在。温度、测试液、供电条件、NPSHr、串联第二级入口压力及滤芯/旁通都未闭，**不是换泵即过**。

Dow原厂著述（2002，大学镜像）50vol% EG 的40°C μ2.2567mPa·s，71.1°C插值μ1.1781，冷液黏度近1.92倍。已列典型ρ/cp/k、层流/光滑湍流压降与Dittus–Boelter膜系数敏感性；ES实际Dh/Re、气侧/鳍效率/壁阻未知，不能把膜系数直接当整体H修正。Dow配方亦不是已确认的 ES 试液。纯水、旧ρ1050/cp3700及该配方不混读。

把六风机215W预算与三泵12V最大电流预算替换旧.86/.12一次，辅助上界2.1475kW。这些是空间/供电预算，不是实际曲线工作点，24V150最大132W/级应另更新。A30min原duties保留后，低热平均2.798–3.221kW、峰4.175–5.316；热平均1.858、峰4.2225；SOC75名义储能7.475–7.757kWh，480最低7.44出现小缺口。高并发B低峰7.995–11.295、热峰6.848，需34.214–36.645kWh，同480不满足该60min问题。

若把高温源H300–380仅作参考，A35°C、24m³/min低路空气、59L/min液路，低路出水约49.27–53.00°C；H×.8自定冷温敏感性则52.77–57.43°C。冷温能力仍红。热路端温、油水HX真正LMTD/F/UA另列，不能只用总热量判定兼容；非额定15/45/90kJ/K瞬态敏感性不替代器件温度限值。

## 电机温度可推进入口

Tecnotion缓存官方2.4/2.5资料：QTL210-65 Tc65Nm/Pc690W/Rth.116K/W，QTR-A160-34-Z Tc15.3/Pc450/Rth.17，均coil100/mount20条件。采用 `Pallowed=min(Psource,(100−Tmount)/Rth)`、`T≈Tsource√(Pallowed/Psource)` 是**明确热阻/电磁不变假设的自定降额研究域**，不是原厂新持续额定。在mount50时约51.37/12.37Nm；若水50且QTL mount-to-water热阻.005–.05，则约50.30–42.95Nm。真实相电流、定子冷板/TIM、热点、速度/母线、stall热分布和驱动损耗必须接回，mount不能直接等于水温，也不能把peak使用成持续。

主动冷却入口已缓存原厂完整 Kodiak：RC009全包318×483×559、dry45kg/水箱4L、20process/20ambient为1050W；230V5.3A给1.219kVA，不是已知真实W/COP。35ambient能力、机器人实际RMS热、AC逆变器、冷凝器排风和motion适配未知；它提供完整研究标尺，没有缩成机器人小chiller或新增第三body宏观。冷凝器仍需拒热Qload+Pcompressor+Paux。
