## 门禁含义

红线阻止对应工程阶段放行；开放项可以继续探索，但不能称稳定物理参数。黄线只描述供应/定制状态，不能替代物理证据。

逐项依据、适用范围与关闭条件见[机器可读门禁清单](../evidence/layout_b_gates.json)。外观审查为独立设计门禁；供应黄线和物理红线可以同时存在，黄线不能关闭红线。

| 门禁 | 当前风险 | 关闭依据 |
|---|---|---|
| 外观：原稿一致性 | 已实看同源四视和主要动作；肩甲/甲面/格栅/掌脚仍为简化代理，尚未放行 | 按原图复原局部曲面及分区，并逐项复核；主要改形须先展示具体冲突和最小调整方案 |
| 红：几何与运动干涉 | 多轴完整模块同心重叠；腕部接触代理和低位/单腿动作有拒绝；线束/工具空间及扫掠仍未知 | 同源真实间隙与完整装配、关键路径扫掠；不能禁碰撞或标黄绕过失败 |
| 红：质量与惯量 | 完整惯量编译回读通过；约 891 kg 自重导致力矩超限；驱动父子分配、转子反射及真实组件仍未闭合 | 重做完整组件质量/空间及驱动拓扑，在同版全机内重算；稳定交接前识别运动部件与转子惯量 |
| 红：结构承力 | 布局多边形不含完整截面、法兰连接、疲劳及紧固证明 | 同版承力链、材料/连接/局部应力和载荷范围闭合 |
| 红：持续驱动与热 | L10 减速器额定不是整关节热连续能力；0.8 系数只是假设 | 电机/减速器/驱动/冷却的同一工作点、电压、温升及持续周期证据 |

## 下一交付与后置事项

本轮已交出同源四视/关键 FK、逐体质量/完整惯量、有限接触静力及拒绝证据；额定载荷、速度和操作安全包络尚不能成立。下一检查点优先在原外包络内重做驱动/传动与内部布局，闭合自重反馈和干涉，再重算能力；不是直接开始 PPO 或把代理图当外观定稿。

后置：非承力倒角、装饰细缝、制造图细化、长期训练和采购。不允许后置后冒充已闭合：主要轴位、质量/空间、承力、持续驱动、供电/回馈、初始非相邻碰撞和交接版本一致性。
