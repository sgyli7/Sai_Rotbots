## 功能预算及语义更正

[预算](functional_budget/README.md)的633行671/783/959kg是选定干子集，不是整机。30min任务问题A与60min高并发B的占空、流量和效率均显式假设，不能当已实现速度/载荷/续航。A总线平均约9.105kW；整数80s6p/480芯参考最低7.44kWh，完整功能条件预算48.2–67.4kg、19.65–33.50L。200V示例电池端约97.35A/16.23A每芯；200–336V只是待适配范围。名义30min有能量余量，最坏效率/SOC需约8.936kWh，不能声称覆盖全域。DC路径效率、储能效率和电芯损失分别记，不重复加。

**root撤销预算中的格栅面积/风速推论：**`.0031172453m²`实际来自液压缸bore cap面积，误当两格栅面积导致68/113m/s等诊断无效。[语义拒绝收据](root_review/functional_throat_area_rejection.json)保留错误原源并明确失效范围；源中`.0459008924m²`也是黑喉gross上界，不等于真实净自由面积。能量/热守恒不受这项面积纠正影响；58项数值算术核通过不能提供参数语义或散热能力通过。G12正按真实格栅/转角风道与一手风机曲线重算。
