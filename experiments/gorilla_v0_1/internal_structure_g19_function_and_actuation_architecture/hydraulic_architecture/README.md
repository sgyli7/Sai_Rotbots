## 保持、并发、回馈、持续热

失压／断电时，比例阀回中位并非真正零泄漏。保持块须就地安装在缸端，保证软管破裂隔离、负载闭合、动态减速与可卸载释放；实际阀座泄漏、瞬态冲击和温升膨胀泄压仍待核。停泵减热必须在该安全链闭合后才使用，不能只把电机功率设零。

并发需要 `Qsum(t)=sum(A_i |J_i(q) qdot_i|)`，以及每支路最高载荷压力+计量／保持／回油压降。旧 F1 18缸0.3rad/s逐支路上界合计148.867L/min，而旧任务供油45/25或60/40L/min仅是任务假设，并非所有轴同时该速度。这份历史库存含4缺缸以及已改路线的腰部，终版列明逐轴压力 unknown，不冻结现有轴数。

阀口／负载下放的功率必须守恒：60L/min经过5bar损失即0.5kW，20bar即2kW。HSP来源中位 P→T 泄漏164mL/min@350bar，若18组均维持该试验压差，热上界1.722kW；未向210bar或卸荷状态线性外推。A不是零保持热；B也不能凭“四象限”删掉当前热账。

局部独立EHA只有实际负功率回路接回泵／电机／DC，且母线或制动电阻能吸收时才回馈。共享泵的异载荷、多轴下放往往仍在阀口节流；100bar×20L/min负机械功率为3.333kW，0.50–0.85回收效率仅是假设，未计任何续航收益。当前完整油、水、冷却和640电芯候选由root统筹，这里不替换库存或冻结母线。

G18的0.5kW“其他aux”没有可靠逐功能拆分，不能静默扣旧180W或再重复加新419.58W。终版给新阀／电子上界，要求下一版本按组件功能替代台账重算同一占空。持续压力／速度、热／效率、回馈和补油需同工况实证，不由供应黄线放行。
