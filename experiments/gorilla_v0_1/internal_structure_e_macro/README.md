# Gorilla E 宏观取舍与选择性混合候选输入

2026-10-03，Asia/Chongqing。父整机仍为冻结 D，E 腿/热探针保留原样。本目录记录两路线[子Agent比较](report.md)、[原始计算](comparison.json)及主线程实际补算的[选择性方案](selective_route.json)。这些参照使用旧 D 的质量、接触、后代树和明确的驱动假设，不是新装配、物理放行或稳定接口。唯一状态以[当前决定](../../../robots/gorilla_v0_1/design/current_decisions.md)为准。

主线程选择**只转换腰 pitch、左右髋 roll、左右足 roll 为成对线性驱动**作为下一 E2 探索输入。保留原八个单缸，合计十三个液压轴、十八缸，并保留十八个完整旋转电驱及十六手部预留。AA3、原甲、高度/比例和双足双手复杂任务目标未更换。

质量只是有限原语＋支承的加法预算；没扣尚未重建的旧壳/架，也没加完整新阀、油液和安装框，不是新整机净重。`t` 是全部同单位归一容量和共同法向分配的参照，不是动力/热认证。最差参照约 1.177，由未改肩 pitch 的目录 L10 标尺控制；该标尺不能当静态硬上限。新增质量与真实串联安装必须重算，所以参照数量不表示 E2 实际通过。

0.1/0.3 是中立同相敏感性，任务不必全轴同时同速，但不能据此保证指定速度。现双泵 3000 rpm 的假设供流约 59.4–64.02 L/min；0.3 的公式需求超过该范围，且力矩、泵转速、压力、电热与负功必须在同工作点闭合。必须计入真实保持/卸荷和能量去向，不默认21 MPa空烧，不用“任务错峰”冒充性能验证。

本次选择旨在避免无必要地将原八缸全部加倍。下一真实 E2 必须共同建立腰/骨盆、髋 yaw/roll/pitch、三段腿、踝/足 roll 和分段脚，以及其全部固定/输出承件、安装壳和管路；允许移动轴位/耳点时重新计算完整有限缸的零眼长、行程与姿态输出。左右不能仅复制容量后忽略镜像轴/反力符号。上下肢、能源、热与检修随后由主线程合成；确需包装改量时仍以同源四视提交用户审美认可。

原宏观脚本与主线程补算分别为 `compare_routes.py.txt`、`selective_route.py.txt`，恢复到原 `.scratch` 位置后用 `.venv/bin/python`运行。旧 C 内皮射线输入可从[冻结 skin_sections](../internal_structure_c/skin_sections.json)恢复，D有限缸输入可从[冻结几何报告](../internal_structure_d/geometry_finite_actuator_report.json)恢复，已核对 SHA 相同；其它输入按原 manifest 和 E0/E探针快照恢复。两条内皮射线不能作为整个安装腔。

原 E 腿报告里“CSG50/QTL160”的文字标签有误：其数字/原几何来源是 D 的 **QTR16034-Z**，不是取得了另一款 QTL160 总成。原冻结证据保留历史哈希；本次及后续来源和型号以 D 参数中的精确引用为准。

原 A/B 比较仅核 LP primal/dual gap，主线程选择性重算进一步实际核对负反力界、归一容量、dual符号、reduced costs及数值差；这仍是浮点诊断，不是区间数学或实物证明。新装配/质量尚未参与，几何、结构、持续驱动、供电/回馈、热、接触、审美与 SI 均未qualified。
