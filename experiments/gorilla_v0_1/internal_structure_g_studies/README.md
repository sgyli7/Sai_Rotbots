# Gorilla G / G1 安装与整体资源研究

本阶段修正原厂安装身份，建立原生有符号材料门禁，并实际生成腰、下腿与手部完整功能候选。**G1 安装均拒绝，未组成新的完整机器人。** AA3 是唯一外观基准，111 件原甲改变 0 mm；诊断投影不代表新审美方案。

## 主线程整体粗算

以下均为明确的条件筛查，不是性能指标、定型自重或可同时成立的运行点。

- [上身与支承位置敏感性](root_macro/torso_support_sensitivity.json.gz)：旧 E2a 已列上身约 772/880/1053 kg，仅作外部负载参照，其材料资格没有因此恢复。COM、支承和轴随 pitch 一起变换，分开轴向、径向、扭转和倾覆；不把倾覆 Mc 当电机扭矩。
- [供油与热敏感性](root_macro/flow_heat_screen.json)：旧 18 缸按限位内侧方向，供油取 cap 或 annulus 单支而不把供回相加。统一 0.5 rad/s 的中立供油约 196.555 L/min，独立 J 极值上界 252.974 L/min；旧两泵 3000 rpm 的 59.4–64.02 L/min 不足以支持该假设。旧拓扑不是 G 的强制要求。泵损耗/理想电池时间与空气 ΔT 粗算没有形成新整机持续能力；原格栅 gross bbox 也不是净开口或已选风机。
- [主梁截面/材料敏感性](root_macro/frame_material_screen.json)：理想 80×100×6、100×140×6、380×110×6 箱梁，以实际旧臂质量加 25/50 kg、1/1.5 倍载荷筛查。Hydro EN AW-6082 资料只支持规定状态与尺寸的挤压材标尺，不能用于铸件、焊接热影响区或实际孔联接资格。新装配重算前不作减重扣账。
- [输入旋转惯量](root_macro/rotary_input_inertia_screen.json)：CSG50/65-100 的已发表输入标量惯量为 0.00125/0.00468 kg·m²。加对应已知转子后，理想固定 parent 的输出反射值约 26.5/136.8 kg·m²，不能替代自由根的耦合动力学或完整逐体 3×3 惯量，也不能与转子重复计量。

首检查点未达标。当前没有新的整机净质量、负载/速度/续航评级、稳定 SI、真实接触任务或 Bevy 放行。供应/定制可后置，未知物理条件仍在对应阶段阻止放行；继续建立条件仿真候选不以实物制造证明为前提。
