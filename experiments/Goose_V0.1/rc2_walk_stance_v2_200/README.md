# RC2 站姿基准、低增益步态试验（保留失败样本）

本目录保存 `goose_rc2_v2` 的 200 轮 RSL PPO 训练检查点、ONNX 策略、元数据与配置。8 个环境、每轮 32 步，共 51,200 环境步。相比 v1，本试验已让训练起姿和动作中心统一为具名 `standing`，腿部位置增益仍为 5 N·m/rad。

[独立回放](../../../robots/Goose_V0.1/evidence/walk_policy_200iter_v2_rc2.json)的静止、前进、后退、左转仍均在约 1.7–2.0 秒跌倒，没有脚部离地。对照静态试验发现同一模型只用重力前馈时低增益站姿也不稳定；后续 `goose_rc2_v3` 改用经过 MuJoCo 与 Godot/Jolt 独立 4 秒站立复测的腿部增益。此 v2 策略只供失败复现，**不得部署**。
