# Project instructions

Before creating, moving or renaming files, read and follow
[sai_robots_engineering_rules.md](sai_robots_engineering_rules.md), the single
source of directory, naming, artifact and migration rules for this repository.

Before showing a Goose design recommendation, concept, CAD view, or finished
appearance, read and apply [the delivery design-review gate](robots/goose_v0_2/design/delivery_review_gate.json).
It links the required industrial-design and Steve Jobs review skills. A draft
label does not waive aesthetic review. Correct failed checks at their source and
repeat affected views before recommending the result; report the reviewed maturity
and unevaluated engineering scope explicitly.
